# Contributing

Use English for README prose, commit messages, and pull requests.

Commit and pull request titles use `type(scope): short English summary`, without ticket IDs.
Use a lowercase snake_case scope and an imperative summary of at most 50 characters, without a final period.
Types are `feat`, `fix`, `docs`, `infra`, `perf`, `refactor`, `style`, `test`, `chore`, `build`, and `ci`.

Examples:

- `feat(audio): add local transcription`
- `fix(network): handle connection timeout`
- `docs(readme): translate setup instructions`

Keep each commit focused on one change.
Describe the problem and resulting behavior in one short sentence, followed by relevant validation results.
